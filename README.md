# YouTube Watch Later Cleaner

Browser extension that removes videos from your YouTube Watch Later playlist.

## Usage

1. Open `https://www.youtube.com/playlist?list=WL`.
2. Click the extension icon.
3. Click **Clean** → **Start**.
4. Closes when done — shows how many were removed.

## Build

```bash
npm install
npm run build
```

Load `.output/chrome-mv3` from `chrome://extensions` (Developer Mode).
